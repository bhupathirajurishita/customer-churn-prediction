# Project progress archive

Use the **Daily progress** issue form after real work on this project: a model experiment, data check, code change, documentation update, or a specific learning result related to customer churn.

The form requires what you worked on, what changed or what you learned, and evidence or a result. Keep the entry factual; do not submit an issue just to fill a calendar square. Check-ins are public because this repository is public, so do not include private data or credentials.

The GitHub Actions workflow archives valid check-ins under `progress/YYYY-MM-DD.md` and closes the issue after archiving. It runs when a check-in is opened and once daily at 18:23 India Standard Time to retry any open check-ins. The scheduled run does nothing when there is no new check-in.

Opening the check-in issue is your activity. The archive commit is made by `github-actions[bot]`; it does not claim that the bot-generated commit was authored by you.
